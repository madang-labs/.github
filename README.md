# 마당

**마당**은 독립적인 시스템이 함께 자라는 열린 작업 공간입니다.

개발, 공부, 지식, AI, 커리어에 쓰는 도구를 만들고 운영합니다.

```text
마당 (madang)
├─ 다채 (dachae)         UI / Design System
├─ 가온 (gaon)           Backend Design
├─ 혜안 (hyean)          Security / Quality Review
├─ 서원 (seowon)         Study Tools
├─ 모은 (moeun)          Knowledge
├─ 슬기 (seulgi)         Dev Agent Orchestration
├─ 이음 (ieum)           Personal Assistant
└─ 나래 (narae)          Career / Portfolio
```

| 시스템 | 뜻 |
|---|---|
| 다채 | 색과 표현의 다양성 |
| 가온 | 서비스의 중심 |
| 혜안 | 꿰뚫어 보는 안목 |
| 서원 | 배우고 익히는 곳 |
| 모은 | 모아 둔 기록과 지식 |
| 슬기 | 지혜로운 판단과 실행 |
| 이음 | 계획과 실행, 회고를 잇는 흐름 |
| 나래 | 날개를 펴고 나아갈 이력과 진로 |

각 시스템은 독립적으로 발전하고, 명시적인 계약과 검증을 통해 연결됩니다.
