# 마당

**마당**은 독립적인 시스템이 함께 자라는 열린 작업 공간입니다.

UI, 서비스, 검증, AI Agent, 개인 지식 시스템을 만들고 운영합니다.

```text
마당 (madang)
├─ 다채 (dachae)         UI / Design System
├─ 가온 (gaon)           Backend / Services
├─ 정결 (jeonggyeol)     Verification / Quality
├─ 슬기 (seulgi)         AI Agent Design
└─ 모은 (moeun)          Second Brain
```

| 시스템 | 뜻 |
|---|---|
| 다채 | 색과 표현의 다양성 |
| 가온 | 서비스의 중심 |
| 정결 | 흔들림 없는 품질 기준 |
| 슬기 | 지혜로운 판단과 실행 |
| 모은 | 모아 둔 기록과 지식 |

각 시스템은 독립적으로 발전하고, 명시적인 계약과 검증을 통해 연결됩니다.
